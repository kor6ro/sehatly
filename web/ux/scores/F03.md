## Alasan per sel (satu fakta; rujukan file bukti)

**Halodoc** (`halodoc.md`): K1 3 — blok cari + pintasan populer + 8 tile spesialisasi teramati; efisiensi hasil tidak dapat diuji (S1/S2). K2 **N/V** — field kartu hasil dokter tidak terender; tidak ada bukti. K3 2 — zero-result hanya "Ubah Lokasi" + panduan tipe kueri; tanpa saran alternatif (S2). K4 N/V. K5 **5** — Bahasa, faskes lokal, phone-first, layanan lokal (S1–S3). K6 3 — direktori dapat dibaca tanpa login; consent/iklan tidak terverifikasi. K7 3 — metadata `<title>` halaman menyesatkan ("Daftar Rumah Sakit") (S1). K8 4 — kotak cari + tile + zero-state bisa dibangun dengan kit yang ada.

**Alodokter** (`alodokter.md`): K1 3 — omnibox + 8 tile spesialisasi; kartu ≈6 field; pagination tak terverifikasi. K2 4 — kartu memuat ketersediaan terdekat, rating+jumlah ulasan, estimasi biaya, faskes sebelum komitmen (S2/S3). K3 2 — zero-result global hanya "cari ulang"; zero-result khusus dokter N/V (S1). K4 N/V. K5 5 — Bahasa, Rupiah, RS lokal. K6 2 — adtech berat (Criteo/GPT/FB Pixel) di halaman kesehatan; pelabelan iklan tidak terverifikasi. K7 3 — rating persentase alih-alih bintang; label "Tersedia Hari Ini". K8 4 — pola kartu/listing dapat dibangun; butuh agregat jumlah ulasan.

**Practo** (`practo.md`): K1 4 — **6 grup filter + 5 opsi sort** teramati, mudah ditemukan; jumlah hasil menonjol. K2 3 — kartu kaya (biaya, pengalaman, % rekomendasi, jumlah patient stories, "Verified doctor details") tetapi **slot iklan "Practo Reach" dijual ke posisi prima** dan pelabelan di SERP konsumen tidak terverifikasi (S3). K3 3 — soft-empty Madurai + "All Filters"; chip filter aktif & zero-result sejati N/V. K4 N/V. K5 1 — India, bahasa Inggris, ₹, faskes India. K6 2 — pemasaran default-in (warisan F05 P11) + risiko sponsored tidak transparan. K7 3 — 6 filter + 5 sort + banner "Call our expert" bersaing dengan hasil. K8 4 — filter/sort/count dapat dibangun; butuh parameter backend.

**Zocdoc** (`zocdoc.md`): K1 3 — Guided Search + filter sadar-asuransi (dokumentasi resmi; live 403). K2 4 — ketersediaan real-time, ulasan terverifikasi, dan **komitmen pelabelan sponsor** dinyatakan resmi (S4). K3 **N/V** — zero-result/pemulihan tidak didokumentasikan. K4 N/V. K5 1 — AS, asuransi AS, bahasa Inggris. K6 3 — ulasan closed-loop, tetapi provider boleh opt-out menampilkan ulasan. K7 3 — ≥8 filter berpotensi membebani; Guided Search membantu. K8 3 — pola filter/sort dapat dibangun; model asuransi tidak ada di Sehatly.

2. Halodoc & Alodokter: kontrol filter/sort/kartu hasil tidak terender via fetch statis.
3. Doctolib & Zocdoc: live SERP 403.
4. Chip filter aktif, pagination, zero-result sejati tidak teramati di kandidat mana pun.
5. Angka benchmark Baymard berasal dari e-commerce, bukan kesehatan.
6. Belum ada uji pengguna nyata; benchmark bukan pengganti uji pengguna.

# Skor F10 — Riwayat dan rekam medis

Tanggal riset: 2026-10-01. Rubrik: `web/ux/rubric.md`. Tanpa bukti = **N/V** (dikeluarkan, bobot dinormalisasi).
Titik awal hitungan (sama semua app): **pasien/peserta sudah login → ingin menemukan rekam medis lama** → tugas inti: **rekaman ditemukan, terbaca, dan bisa diunduh** (bila unduhan tidak tersedia di app, dicatat sebagai keterbatasan, bukan nol otomatis).
Bukti per app: `web/ux/evidence/F10/*.md`. Kandidat domain lain (`nng-history-search.md`, `wcag-22-tables.md`, `bank-history.md`, `onc-patient-access.md`) **tidak dinilai sebagai aplikasi** — dipakai sebagai sumber pola langkah.

**Sumber independen** = penerbit berbeda dengan bukti terverifikasi (langsung atau via indeks pencarian 2026-10-01, ditandai).
- MyChart: Epic (mychart.org, 5 laman langsung) + Johns Hopkins tip sheet + Middlesex Health guide = **3 penerbit** ✓ (2 panduan via indeks pencarian).
- NHS App: nhs.uk (3 laman langsung) + digital.nhs.uk (403 → indeks) = **1 organisasi penerbit (NHS England)** → uji independensi **gagal**.
- Apple Health Records: support.apple.com (3 laman langsung) + developer.apple.com = **1 penerbit (Apple)** → gagal.
- SATUSEHAT: satusehat.kemkes.go.id (dokumen+FAQ) + kemkes.go.id (press) + Play Store listing = **2 sumber** (situs resmi ≠ store listing) ✓.
- MySiloam: Play Store + App Store listing = **2 sumber** ✓ (situs resmi SPA tak render).
- Mobile JKN: manual resmi bpjs-kesehatan.go.id + Play Store + App Store + press (IDX Channel, eHealth.co.id, Pojok Satu) = **≥3 penerbit** ✓.
- Halodoc: FAQ resmi + S&K = **1 penerbit (halodoc.com)**; data-safety store tidak difetch → gagal.
- Alodokter: S&K + privasi + Play Store + press = **≥2 penerbit** ✓, tapi bobot terverifikasi jauh di bawah 70%.

Tidak ada app yang diberi red flag **diskualifikasi** sebagai sumber pola utama (tidak ditemukan hitung mundur palsu/upsell menyembunyikan aksi); red flag per app tetap dicatat dan elemen yang ditandai tidak boleh disalin.

## Yang TIDAK TERVERIFIKASI (membatasi keyakinan)

1. **Seluruh layar dalam aplikasi** (semua app native/portal di balik login) — hitungan layar/ketukan = dari langkah terdokumentasi, bukan pengamatan langsung.
2. **K4 Aksesibilitas untuk SEMUA app = N/V** (15% bobot hilang untuk semua) — tak ada pengukuran kontras/target sentuh/pembaca layar app acuan.
3. **State loading/error/offline untuk semua app**; state kosong hanya terindikasi via judul FAQ SATUSEHAT dan kondisi bersyarat Halodoc.
4. **Hitungan end-to-end** "temukan → baca → unduh" tidak dinyatakan sumber mana pun.
5. Badan FAQ SATUSEHAT (dirender JS "Loading..."); situs & kebijakan privasi MySiloam (SPA); halaman privasi Halodoc (404); digital.nhs.uk (403); PDF Hopkins (403, via indeks, bertanggal 2022).
6. Keberadaan **unduh/ekspor PDF** untuk SATUSEHAT, MySiloam, Mobile JKN, Alodokter — **tidak ditemukan bukti; jangan disimpulkan ada**.
7. Aplikasi native tidak bisa diakses langsung (tanpa emulator/tanpa akun) — batasan riset sesuai aturan.
8. **Artikel NN/g khusus "timeline design" tidak ditemukan** → jangan disitasi (klaimnya TIDAK TERVERIFIKASI).

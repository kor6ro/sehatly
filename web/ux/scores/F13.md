# Skor F13 — Dashboard dokter (jadwal, antrean, catatan, tulis resep)

Tanggal riset: 2026-10-01. Rubrik: `web/ux/rubric.md`. Tanpa bukti = **N/V** (dikeluarkan, bobot dinormalisasi).
Titik awal hitungan (sama semua app): **dokter membuka aplikasi di sela pasien** → tugas inti: **konsultasi dimulai / resep ditulis**.
Bukti per app: `web/ux/evidence/F13/*.md`.

## Catatan rubrik (WAJIB — penggantian kriteria 5)

Untuk flow **F13**, kriteria 5 rubrik **"Ketahanan konteks Indonesia" DIGANTI** menjadi **"Efisiensi pengguna berulang"**: shortcut keyboard, aksi/banding massal, dan kepadatan informasi yang tetap terbaca (sumber: `evidence/F13/linear-notion.md`, `nng-baymard.md`). Alasan: F13 adalah alur kerja dokter yang diulang puluhan kali sehari; jaringan/QRIS bukan variabel utama layar ini.

**Adaptasi bobot** (total tetap 100%): kriteria 5 naik **10% → 15%** (kini inti flow); kriteria 2 (Kejelasan & kepercayaan) turun **15% → 10%** karena F13 = alur internal tanpa komitmen harga pasien (unsur "biaya sebelum bayar" tidak ada di layar dokter; kejelasan status tetap dinilai di kriteria 2 pada bobot baru). Kriteria lain: 1 = 20%, 3 = 15%, 4 = 15%, 6 = 10%, 7 = 10%, 8 = 5%.

**Skor ≠ popularitas**: klaim "1 juta pengguna" Doxy.me / "250k praktisi" SimplePractice **tidak** menaikkan skor apa pun (rubrik: popularitas ≠ kualitas).

**Red flag (aturan tugas):** **SimplePractice** kena red flag **notification overload** — bunyi join/leave "no way to turn this sound off" (`evidence/F13/simplepractice.md` S1) dan alert email ePrescribe "required and can't be disabled" (S4) → **dinilai di tabel, tetapi TIDAK BOLEH jadi sumber pola** di `patterns/F13.md`. Kandidat lain: tidak ditemukan red flag diskualifikasi (upsell Doxy/Practo/Doctolib tidak menutupi aksi utama; harga Jane/add-on transparan).

**Sumber independen** = penerbit berbeda (vendor ≠ aggregator ulasan ≠ media/pengadilan ≠ store listing):
- Doxy.me: help center Doxy + **G2** + **TrustRadius** + **Tracxn** → 3 penerbit independen ✓
- Jane: guide vendor + **Medesk** (tinjauan 2026) + **store listing** → 3 ✓
- SimplePractice: help center + **Medesk** + **BusinessWire** + **App Store** → 4 ✓ (tapi red flag → bukan sumber pola)
- Practo Ray: help center + **dokumen pengadilan/audit** + **iTechGuides** + **Times of India** → 4 ✓
- Doctolib: help center + komunitas Doctolib (sama) + **Google Play** + **CB Insights/CB** → ≥2 penerbit independen ✓

## Yang TIDAK TERVERIFIKASI (membatasi keyakinan)

1. **Seluruh skrin dalam aplikasi** (semua app di balik login; tidak ada akun dibuat) — hitungan layar/ketukan = dari langkah terdokumentasi, bukan observasi.
2. **Aksesibilitas nyata** (kontras, target sentuh, SR) untuk Doxy/Jane/SP/Practo/Doctolib = **N/V di produk web** (hanya listing iOS atau klaim artikel).
3. State loading/kosong/offline in-product untuk semua app (kecuali yang disebut eksplisit di file evidence).
4. Shortcut keyboard di Practo/Doxy (tidak ada artikel shortcut publik) — skor K5 keduanya bertumpu pada aksi massal/urutan/kepadatan yang terdokumentasi.
5. Kontradiksi Doxy: "SOAP notes di produk" (marketing) vs "dokumentasi di EHR" (help) — tak bisa diputuskan tanpa akun.
6. Ketersediaan fitur "paid versions only" Doctolib untuk semua wilayah (satu artikel help).
7. K6 Practo & Doctolib = N/V (privasi tak diverifikasi) → bobot keduanya 90%.
8. Aplikasi native tak bisa diakses langsung (tanpa emulator/akun) — batasan riset sesuai aturan; Doxy bahkan **tanpa app** (aplikasi mobile lama sudah didekomisikan, kini browser-only [doxy-me evidence, help 95856]).

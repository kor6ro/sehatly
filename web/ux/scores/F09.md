## Yang TIDAK TERVERIFIKASI (membatasi keyakinan)

1. Seluruh **skrin dalam aplikasi** (semua app native/portal di balik login) — hitungan layar/ketukan = dari langkah terdokumentasi, bukan pengamatan langsung.
2. **Aksesibilitas nyata** (kontras, target sentuh) untuk Halodoc, Kimia Farma, MyChart, Medisafe = **N/V**.
3. State loading/kosong/offline untuk semua app (kecuali state error terdokumentasi Halodoc & Apple).
4. Opsi ambil-di-apotek di Halodoc/Kimia Farma 2026.
5. Isi Lampiran X/XI PerKa BPOM 24/2017 dan status hukum 24/2017 vs 15/2023.
6. Aplikasi native tidak bisa diakses langsung (tanpa emulator/tanpa akun) — batasan riset sesuai aturan.

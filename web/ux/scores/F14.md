# Skor F14 — Admin klinik (dokter, jadwal, laporan)

Tanggal riset: 2026-10-02. Rubrik: `web/ux/rubric.md`. Tanpa bukti = **N/V** (dikeluarkan, bobot dinormalisasi).
Titik awal hitungan (sama semua app): **admin klinik membuka aplikasi** → tugas inti (ubah jadwal / kelola dokter-akses / lihat laporan).
Bukti per app: `web/ux/evidence/F14/*.md`.

## Catatan rubrik (WAJIB — penggantian kriteria 5)

Rubrik baris 24: untuk flow **dokter dan admin (F13, F14)**, kriteria 5 **"Ketahanan konteks Indonesia" DIGANTI** menjadi **"Efisiensi pengguna berulang"** (shortcut, aksi massal, kepadatan informasi yang tetap terbaca). Bobot default dipertahankan (total 100%): K1 20%, K2 15%, K3 15%, K4 15%, K5 10%, K6 10%, K7 10%, K8 5%. Tidak ada adaptasi bobot tambahan (berbeda dari F13 yang menaikkan K5) — F14 memang pekerjaan berulang, tetapi tiga kriteria lain (kejelasan status, privasi, aksesibilitas) sama pentingnya untuk data kredensial dan audit, sehingga bobot default dianggap paling jujur.

**Red flag (aturan tugas):** tidak ada kandidat F14 yang didiskualifikasi. Catatan yang **tidak ditiru**: Trustmedis menghapus jadwal **tanpa dialog konfirmasi** (hanya notifikasi kegagalan) → §3 pattern menolak pola itu; Practo Ray aksesibilitasnya rusak-terdokumentasi (audit 2025 + perintah pengadilan) → tidak dipakai sebagai sumber pola aksesibilitas.

**Sumber independen** = penerbit berbeda (vendor ≠ agregator ulasan ≠ media/pengadilan ≠ regulator):
- Klinik Pintar: help center + blog/situs produk → **1 penerbit** (semua Klinik Pintar)
- Trustmedis: KB + situs produk + blog → **1 penerbit**
- Practo Ray: help center + **audit/pengadilan** + **berita Times of India** (via `evidence/F13/practo-ray.md` S8/S9/S11) → ≥2 penerbit ✓
- Jane: panduan vendor + **Medesk review 2026** + **Google Play listing** (via `evidence/F13/jane-app.md` S9/S10) → ≥2 penerbit ✓
- Shopify: help center + changelog → **1 penerbit**
- GitHub: docs + NIST (standar, bukan tentang GitHub) → **1 penerbit untuk klaim produk**

## Pemenang

- **Pemenang skor keseluruhan tertinggi: Shopify (4,29 @85%)**, tetapi **gagal syarat independensi** (semua sumber dari Shopify) → **tidak boleh diklaim sebagai pemenang rubrik**; dipakai sebagai **sumber pola langkah** (bulk, audit-log limitations).
- **Pemenang rubrik yang sah: Jane App (3,85 @100%, ≥2 penerbit independen).** Namun Jane **tidak menutup** verifikasi kredensial STR/SIP (khas Indonesia), publish jadwal, dan audit trail bertingkat — jadi pattern F14 memakai **pemenang per langkah (best-of)**, sama seperti F13/F09.

## Yang TIDAK TERVERIFIKASI (membatasi keyakinan)

1. **Sisi dalam semua aplikasi kandidat** (di balik login): layout, state loading/kosong/error/offline, jumlah klik presisi — semua klaim langkah berasal dari dokumentasi, bukan observasi.
2. **Aksesibilitas Klinik Pintar, Trustmedis, Shopify, GitHub = N/V** (tidak ada dokumen aksesibilitas publik yang diakses); Jane hanya punya panduan tanpa klaim WCAG; Practo Ray punya bukti negatif.
3. **Audit trail & konfirmasi destruktif Klinik Pintar/Trustmedis = tidak terdokumentasi** — jangan mengklaim mereka punya atau tidak punya.
4. **Pengelolaan jadwal (tulis) Practo Ray tidak ditemukan** di help center pada sesi ini → skor K1-nya bertumpu pada kelola staf & laporan.
5. **Batas export** (jumlah baris/rentang) untuk Klinik Pintar & Jane tidak dinyatakan; hanya Shopify/GitHub yang eksplisit.
6. **Independensi sumber**: hanya Jane & Practo Ray yang memenuhi; Shopify (skor tertinggi) tidak eligible jadi pemenang.
7. **Zona waktu** penjadwalan tidak didokumentasikan di kandidat mana pun.

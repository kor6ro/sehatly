## Temuan persis

- **S1:** *"Faceted navigation is composed of multiple filters that comprehensively describe a set of content."* *"The extra power of faceted navigation also adds interaction cost by presenting users with more options to comprehend and manipulate."*
- **S2:** lima alasan pencarian tidak cukup — *"Search Requires Knowledge of the Search Space"*; *"Search Increases Memory Load"*; *"Search Has Higher Interaction Cost than Browsing"*; *"Site Search Often Works Poorly"*; *"Users Have Poor Search Skills."* *"Navigation serves important functions: it shows people what they can find on the site."* Facet *"transform search into navigation."*
- **S3 (zero-result):** tiga panduan — (1) *"Clearly explain that there are no matching results"*; (2) *"Offer starting points for moving forward"*; (3) *"Don't mock the user."* *"Most No Results pages are dead ends that don't offer any suggestions about what to do next."* Daftar pemulihan: ulangi kueri, pertahankan kueri asli di kotak, saran kueri serupa, koreksi ejaan, saran modifikasi kueri.
- **S4 (empty state):** *"Search results lists when nothing is found"* adalah kasus empty state eksplisit; *"Provide direct pathways (i.e., links) to getting started with key tasks."*
- **S5 (mobile tray):** kontrol facet mobile dalam **tray overlay**; hasil tetap terlihat di belakang; *"The total number of results is always visible"*; gunakan kata nyata ("Filter", "Refine"), bukan ikon kriptik.
- **S6 (filter intent):** *"Let users tell you when they're done selecting filters… include an Apply button… recommended approach on mobile devices."* Jangan menggulir halaman kembali ke atas setelah filter; redupkan hasil + indikator progres.
- **S7:** filter harus *"appropriate, predictable, free of jargon, and prioritized"*; hindari label kabur seperti "Item Type"; di mobile sering memakai *"collapsed accordions"*.
- **S8:** faceted search *"has become expected rather than exceptional"*; sorting skor review harus berbobot (hindari 5 bintang dari 1 ulasan); kegagalan umum: presentasi hasil nonstandar (pagination, sorting, filtering) dan *"Poorly executed filters (irrelevant attributes, bad functionality, empty result sets)."*
- **S9 (lintas konteks):** filter di kiri, terbuka default, checkbox multiselect; **tampilkan jumlah item per nilai filter**; dropdown sort di kanan atas; *"Use pagination… Avoid using lazy loading or infinite scroll."*
- **S10:** pertahankan field teks terbuka di samping ikon di desktop; ikon saja *"makes it much harder to locate the search."*

## Red flag

Tidak ada. Catatan: S9 berasal dari konteks intranet dan dinyatakan umum — diterapkan hati-hati.
